BUG FIXES (v2 — user ke pehle test ke baad)
================================================================
User ne bataya: (1) window minimized nahi hoti, maximized khulti hai
(2) doosra run chalane pe CREATE ACCOUNT pe atakta tha (acc1 ki
detail file se gayab ho gayi) (3) cookies clear nahi hoti thi.

FIX 1 — MINIMIZE:
  Root cause: purana minimize.ps1 launch ke turant baad EK hi baar
  EnumWindows karta tha — us waqt Chrome ki window bani hi nahi hoti
  thi -> milti nahi -> silent no-op -> window maximized rehti thi.
  (Diagnose kiya tha: scriptblock $ProcessId scoping sahi hai —
  test se confirm, timing hi issue tha.)
  Fix: minimize.ps1 ab 15s ka retry loop chalata hai — jab tak
  window na mile, har 400ms try; minimize karke IsIconic se verify
  + 5 baar stable (~3.5s) rehne pe exit 0. Node pe spawn (non-blocking)
  + first page load ke baad ek DUSRA minimize call (insurance).
  Exit code 0/1 log hota hai. --start-maximized rehne se taskbar
  click pe FULL maximized restore hota hai (user ki condition 2 OK).

FIX 2 — APIS.TXT DATA LOSS:
  Root cause: overwriteOutput=true har run ke SHURU me file truncate
  kar raha tha -> purane accounts gayab.
  Fix: overwriteOutput=false default; agar koi true kare toh pehle
  timestamped BACKUP banake hi truncate. Aur numbering ab purani
  file se CONTINUE hoti hai (acc1..acc4 purane + naye acc5...)
  -> kabhi overwrite nahi, sab append. Write ab bhi capture ke
  turant baad hota hai + partial data bhi likha jata hai
  (api/fingerprint me se jo mile), khali throw nahi.

FIX 3 — CREATE ACCOUNT PE ATTAK:
  Root cause: account 1 ke baad purana session/storage (cookies,
  localStorage me username/fingerprint) properly clear nahi ho raha
  tha -> site purane state ke saath create reject karti thi ->
  fingerprint popup hi nahi aata tha (40s timeout tak atakta tha).
  Fixes (layered):
  a) Deep clear: CDP Network.clearBrowserCookies + clearBrowserCache
     + Storage.clearDataForOrigin(origin, 'all') + localStorage/
     sessionStorage.clear() — har account ke baad.
  b) ensureSignedOut(): har account se pehle goto + verify
     (html[data-signed-in] + SIGN IN link) — signed-in mila toh
     3 baar deep clear + reload. Signed-out confirm hone pe hi aage.
  c) Duplicate username guard: agar prefill username pehle se
     apis.txt me hai (16/20 wo prefill tha jo phas raha tha) ->
     Regenerate button 3 baar click naya username lo.
  d) CREATE ACCOUNT retry: 3 attempts, har ek ka 15s wait; fail pe
     dialog ka poora text (site ka exact error) + 4xx/5xx HTTP
     response bodies (attachHttpLogger) log hoti hain — agli baar
     exact wajah console me dikh jayegi.
  e) continueOnError=true (default): ek account fail ho toh run
     band nahi hota, screenshot debug/error-accN.png save hota hai
     aur next account try hota hai. maxConsecutiveFailures=3: lagatar
     3 fail pe hi run rukega (bina wajah ke 100 accounts waste nahi).
  f) betweenAccountDelayMs=4000: accounts ke beech 4s pause
     (rate-limit kam).

NEW CONFIG KEYS (config.json):
  overwriteOutput:false | betweenAccountDelayMs:4000 |
  continueOnError:true | maxConsecutiveFailures:3
  (accounts, url, outputFile, startMinimized, keepOpenAtEnd,
   stepDelayMs, timeoutMs pehle jaise)

AGAR AGLE TEST ME CREATE FAIL HO:
  -> console ka "NET: HTTP ..." aur "DIALOG: ..." line bhejo,
     exact server error dikhega. debug/error-accN.png bhi banta hai.

FILES (ban chuki hain)
================================================================
- package.json     → puppeteer dependency, npm start script
- config.json      → url, accounts (USER SET KAREGA), outputFile,
                     overwriteOutput, startMinimized, keepOpenAtEnd,
                     stepDelayMs, timeoutMs
- extractor.js     → poori automation (launch → signup → capture →
                     allocate → write → clear → loop)
- minimize.ps1     → Windows pe browser window ko taskbar me minimize
                     karta hai (user32 EnumWindows + ShowWindow(6));
                     Chrome --start-maximized se launch hota hai isliye
                     taskbar click pe FULL maximized restore hota hai
- start.bat        → cd to folder, npm install (agar node_modules na
                     ho), node extractor.js, pause
- apis.txt         → output (run ke waqt banta hai)
- debug/           → error screenshots (error-accN.png)

Browser launch args: --start-maximized, --disable-background-timer-
throttling, --disable-backgrounding-occluded-windows,
--disable-renderer-backgrounding (minimized rehne pe bhi automation
chalti rahe), defaultViewport: null, headless: false.

Clipboard permission: origin pe overridePermissions(['clipboard-read',
'clipboard-write']) — API key clipboard se padhne ke liye.

API key capture order (fallback chain):
  1. Copy buttons se clipboard read (validate /^dahl_/)
  2. "DOWNLOAD AS .TXT" → temp dir me file → parse
  3. Network sniff (response bodies me /dahl_[A-Za-z0-9]{8,}/)
